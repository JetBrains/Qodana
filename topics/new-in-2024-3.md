Several changes were implemented in the version 2024.3 of %product%: 

* The taint analysis feature is available for the [%jvm%](jvm.md) linter, see the [](taint-analysis.md) section.
* The new version of the data flow analysis (DFA) inspection was implemented for the [%go%](golang.md) linter, see the [GoLand](%dfa-link%) documentation for inspection details.
* The [%jvm-a%](jvm.md) and [%jvm-co-a%](jvm.md) linters now support new inspections. The list of inspections is available on the [GitHub](%android-link%) website.
