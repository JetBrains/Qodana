Version 2025.1 of %product% contains several updates.

## Kotlin K2 Mode

The Kotlin K2 mode is by default enabled for the Qodana for JVM and Qodana Community for JVM [linters](jvm.md). 
This update aligns with JetBrains’ move towards K2 in IntelliJ IDEA 2025.1 and offers improved performance and stability, 
along with new Kotlin 2.1 feature support.

Potential issues to be aware of:

* Third-party plugins might not support K2 yet
* Some inspections are still not implemented, see the [details](%k2-ref%).

To revert the K2 mode, in your linter configuration set the `idea.kotlin.plugin.use.k2` 
[property](docker-image-configuration.topic#docker-config-reference-properties) to `false`. 


## Improved Incorrect Formatting inspection

The  [`IncorrectFormatting`](%incorrect-formatting%) inspection consolidates multiple formatting errors contained in 
a file into a single problem instead of listing every issue separately. Now, a single problem per file is displayed with 
example snippets to help you fix issues faster.

This feature is available for all [linters](linters.md) except %cpp%, %clang%, and %dotnet-co%. 

To start using it, enable the `IncorrectFormatting` inspection in your %product% 
[inspection profile](inspection-profiles.md) configuration, for example:

```yaml
include:
  - name: IncorrectFormatting
```

## New Qodana for C/C++ linter

Starting from version 2025.1 of %product%, you can analyze your C and C++ projects using two %product% linters. 

The new %cpp% linter supports all Clang-Tidy inspections supported by %clang%, as well as 
[MISRA](%misra%) and dataflow analysis-based inspections. 

The existing %clang% linter supports only Clang-Tidy inspections. 

The details are available on the [](clang.md) page of the documentation.

## Visual Studio integration

Using %product% plugin for Visual Studio, you can explore %product% reports and connect to Qodana Cloud, see the [Visual Studio](visualstudio.md)
section for details.

## OWASP Top 10

%product% now provides predefined taint rules for A01, A03, A07, A08, A10 categories of OWASP Top 10:2021 vulnerabilities. 
These rules significantly enhance security issue detection by minimizing user effort while ensuring broad security 
coverage, and provide:

* Automatic detection for common security flaws
* 700+ new configuration entries covering common frameworks and libraries
* The ability to customize taint rules using KTS files to define sources and sinks

For details, see the [](taint-analysis.md) section.

## Native mode support

As of version 2025.1, %product% provides the [native mode](native-mode.md) for the following linters:

* [%jvm%](jvm.md)
* [%jvm-co%](jvm.md)
* [%php%](php.md)
* [%js%](js.md)
* [%dotnet%](dotnet.md)

## Enhanced GitLab CI/CD and Azure Pipelines integration

Starting from 2025.1, %product% provides the %instance% Scan GitLab Pipeline [component](%GitLabComponent%) for analyzing
code using GitLab CI/CD, which means that you can use a native solution instead of Docker images. Besides that, the 
component supports [quick-fixes](quick-fix.md) and analysis of merge requests. The details are available on the
[](gitlab.md) page of the documentation.

The [Qodana Azure Pipelines extension](qodana-azure-pipelines.md) also supports [quick-fixes](quick-fix.md), see the 
[](qodana-azure-pipelines.md) page for details.
