# Analyze your code

To analyze your project using %product%, follow the steps listed below.

1. Choose the %product% [linter](linters.md) that you would like to use. 
1. Decide which [deployment method](deploy-qodana.md) of %product% you would like to use.   
1. Configure %product% as described on the [](configure-qodana.md) page.
1. If necessary, set up the list of commands that will be executed before %product%, see the [](before-running-qodana.md)
    section for details.
1. In %cloud%, [set up your account](cloud-quickstart.md) and obtain a [project token](project-token.md). 
1. Follow recommendations from a linter page that you would like to use (Step 1).
1. If necessary, follow recommendations from the [](troubleshooting.topic) section.
